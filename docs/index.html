INSTALL

بدون نصب، بدون پایتون

نسخه‌ی آماده یک فایل اجرایی تک است؛ دانلود کنید و اجرا کنید.

  1. دانلود

    فایل ProImageConverter.exe را از صفحه‌ی Releases یا دکمه‌ی بالای صفحه بگیرید.

  2. اجرا

    اجرایش کنید. اگر SmartScreen هشدار داد، روی More info و سپس Run anyway بزنید.

  3. تبدیل

    پوشه‌ی ورودی را انتخاب کنید، فرمت و کیفیت را تعیین کنید و «شروع تبدیل» یا Ctrl+Enter را بزنید.

# اجرا از سورس (Python 3.11+)
git clone https://github.com/mr-shady/ProImageConverter.git
cd ProImageConverter
python -m pip install -r requirements.txt
python app.py

# پشتیبانی اختیاری SVG و RAW
python -m pip install -r requirements-optional.txt

# ساخت فایل اجرایی
build_exe.bat
FAQ

سؤال‌های رایج

آیا تصاویر من جایی ارسال می‌شوند؟

نه. برنامه کاملاً آفلاین کار می‌کند و هیچ اتصال اینترنتی لازم ندارد. بخش «امتحان آنلاین» همین صفحه هم فقط داخل مرورگر شما اجرا می‌شود.

چرا خروجی SVG ندارد؟

تبدیل تصویر پیکسلی به SVG واقعی «وکتورسازی» است، نه تغییر فرمت. ورودی SVG پشتیبانی می‌شود و به هر فرمت پیکسلی تبدیل می‌شود.

اگر پوشه‌ی خروجی داخل پوشه‌ی ورودی باشد چه می‌شود؟

مشکلی نیست؛ برنامه پوشه‌ی خروجی را از اسکن حذف می‌کند تا فایل‌های تبدیل‌شده دوباره پردازش نشوند.

میانبرهای صفحه‌کلید چیست؟

Ctrl+O انتخاب پوشه‌ی ورودی، Ctrl+Enter شروع تبدیل و Esc لغو عملیات.
